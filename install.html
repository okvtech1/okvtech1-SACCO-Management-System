Install on Android

  1. Open this link in Chrome.
  2. Tap Install App above.
  3. Confirm Install on the prompt.
  4. Open the app icon from your home screen, then sign in.

Install on iPhone / iPad

  1. Open this link in Safari (not Chrome).
  2. Tap the Share icon .
  3. Tap “Add to Home Screen”, then Add.
  4. Open the app icon from your home screen, then sign in.

Install on Windows / Mac

  1. Open this link in Chrome or Edge.
  2. Tap Install App above, or click the install icon in the address bar.
  3. Click Install to confirm.
  4. Open the app from your desktop, then sign in.
