Backup

Download or restore your organization's full data

Download a Full Backup

Downloads every Member, Contribution, Loan, Repayment and Dividend record in one file. Keep it somewhere safe — it can fully restore your data if needed.

Restore From a JSON Backup

Restoring adds records from the backup file into your organization — it does not erase anything currently there. Existing records with the same ID are updated; new ones are added.
